Self-Hosting Guide

Deploy on Your Own Server in 60 Seconds

100% open-source and comes ready with PM2 configuration for permanent 24/7 uptime on Oracle Cloud or any Linux VPS.

bash — ubuntu@cloud-instanceFrosty Setup
# 1. Clone Frosty Repository
git clone https://github.com/Zcross091/frosty-wos-ai.git
cd frosty-wos-ai

# 2. Install Python Dependencies
pip install -r requirements.txt

# 3. Configure .env with your free keys (Discord Token + Gemini/Groq)
cp .env.example .env

# 4. Clean-Ingest Local Knowledge Base into ChromaDB
python3 ingest.py --local-only --clean

# 5. Start 24/7 Background Process via PM2
pm2 start ecosystem.config.js
pm2 save
