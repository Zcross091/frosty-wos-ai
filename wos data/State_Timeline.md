# Whiteout Survival Master State Timeline & Server Age Unlock Guide

In **Whiteout Survival**, server progression is strictly gated by **State Age** (the total number of days elapsed since the server was created). All major features—including Hero Generations, Fire Crystal tiers, Pet Generations, Chief Gear, the War Academy, Sunfire Castle, and State vs State (SvS)—unlock sequentially based on this timeline.

## 🔍 How to Check Exact Server Age
1. **Monument Method (Most Accurate):** Look at the **"Kindling Embers"** achievement under the in-game Monument. The "Goal Met" timestamp corresponds to Day 1 or Day 2 of server launch.
2. **VIP Consecutive Login:** If you started on day 1 of the server opening, your VIP consecutive login count equals your exact server age.
3. **State Number Formula:**
   - State 1–100: ~1300–1400 Days
   - State 101–500: ~1000–1250 Days
   - State 501–1000: ~450–900 Days
   - State 1001–1500: ~150–400 Days
   - State 1501–2000: ~40–150 Days
   - State 2001+: ~1–40 Days
