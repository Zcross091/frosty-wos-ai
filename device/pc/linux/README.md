# Linux Desktop Engine for Frosty WOS AI
This directory contains the native GTK3 Linux desktop embedder and build configurations for Ubuntu / Debian / Fedora / Arch Linux.
To compile on Linux:
```bash
cd device/mobile
flutter build linux --release
```
The output binary will be generated at `device/mobile/build/linux/x64/release/bundle/frosty_wos_ai`.
